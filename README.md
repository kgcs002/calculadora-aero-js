## 📖 Sobre o Projeto

Simulador web que calcula e exibe a trajetória de voo de uma aeronave usando princípios físicos básicos. Desenvolvido como parte dos meus estudos em Engenharia Aeroespacial e JavaScript.

**Características principais:**
- Cálculo em tempo real da trajetória parabólica
- Determinação automática da altura máxima
- Gráfico interativo da trajetória
- Design temático de aviação

---

## 🚀 Funcionalidades

- ✈️ Simulação de trajetória com base em velocidade, ângulo e tempo
- 🏔️ Cálculo preciso da altura máxima alcançada
- 📊 Visualização gráfica dinâmica usando Plotly.js

---

## 🛠️ Tecnologias Usadas

- **Frontend:** HTML5, CSS3, JavaScript
- **Bibliotecas:** Plotly.js
- **Design:** CSS puro com efeitos modernos
- **Assets:** Imagens gratuitas do Unsplash

---

## 🎯 Como Usar

1. Acesse: https://calculadora-aero-js.vercel.app/

**Dica:** Experimente ângulos entre 30° e 60° para trajetórias mais interessantes!
